## 스크립트가 하는 일

1. 열려 있는 《국부론 수업》 문서에서 다음을 **새 문서**로 가져온다. 원본은 고치지 않는다.
   - 문단·문자·개체·표 스타일
   - 색상 견본
   - 부모 페이지
2. 새 문서를 판형 150×214mm, 여백 위 19.5 / 아래 31 / 안쪽 27 / 바깥 22mm, 도련 3mm로 설정한다.
3. 장마다 순서대로 놓는다.
   1. 도비라 펼침면(짝수·홀수 쪽): 오른쪽 면에 도비라 자리와 장 번호·제목
   2. 본문: 첫 쪽부터 넘치는 만큼 쪽을 늘려 이어 흘린다
4. 도판 자리마다 시안과 같은 크기의 회색 인라인 상자를 넣는다. 쪽수를 실제와 가깝게 하려는 것이다.
5. 끝나면 쪽수와 확인 항목을 알린다.

## 문단 스타일 대응

| 원고 요소 | 문단 스타일 | 구분 |
|---|---|---|
| 본문 | 본문 (명조Neo1 02 Lt 11.5/26pt, 들여쓰기 5mm) | 레퍼런스 |
| 절 제목 (##) | **절 제목**: '대제목'을 바탕으로 새 쪽 시작만 끔, 앞 39pt | 제안 |
| 번호 소제목 "1) …" | **소제목** = '큰 제목' (스터디윗미 Bold 13pt) | 레퍼런스 |
| 번호 없는 ###, ■ 제목 | **소소제목**: 고딕Neo1 07 Bd 10.5pt | 제안 |
| '잠깐!' 상자 | **잠깐 라벨**('만화 대사' 바탕) + **잠깐 본문**. 문단 음영은 국부론 상자색 0/6/68/0 | 제안 |
| 글머리 목록 / 번호 목록 | 목록 / 번호 목록(내어쓰기) | 제안 |
| □ 질문 | 질문 제목(도해_청록) | 제안 |
| 기사 제목 예시(기울임) | 본문 삽입 | 레퍼런스 |
| ▣ 도판 | 도판 자리 + 회색 상자 | 제안 |
| 자료와 출처 | 참고 자료(고딕Neo1 Lt 8/12pt) | 제안 |

## 확인 필요

- **절 제목의 새 쪽 시작을 껐다.** 국부론 '대제목'은 매번 새 쪽에서 시작한다. 이번 원고는 절이 짧고 많아(1장 10개) 빈 면이 많이 생기기 때문이다. 국부론과 똑같이 하려면 '절 제목'의 [단락 시작]을 '다음 페이지'로 바꾸면 된다.
- **'잠깐!' 상자 안 문단 구분**
  - 내보낸 원고에서는 상자 안 문단이 이어 붙어 있어 구분을 확인할 수 없다. 그래서 상자 하나를 한 문단으로 넣었다.
  - 원본 Docs와 대조해 줄을 바꿔야 한다. 예: 1장 크록 상자의 "맥도날드의 창업 이야기는…"
- **번호 소제목**은 원고 번호 "1) 2) 3)"를 그대로 썼다.
- **제외한 것:** 4장 끝 편집 메모 "트럼프 이야기는 조금 민감한 내용일 수 있어서…"
- **본문 속 출처 번호** `[2-3]`, `[3-7]`은 원고대로 두었다.
- **도판:** 아직 시안 PDF를 놓지 않았다. 회색 자리에 `시안/도…_실제크기.pdf`를 놓거나, 제작 지시대로 인디자인에서 다시 짠다.
- **쪽번호·러닝헤드**는 국부론 부모 페이지를 따른다. 앞부속(표제지·판권·차례·프롤로그)은 아직 넣지 않았다.
- **인디자인 실행 검증 전이다.** 이 클라우드 환경에는 인디자인이 없어 문법 검사만 했다. 반드시 새 문서에서 결과를 확인한다.
