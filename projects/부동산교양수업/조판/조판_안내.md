## 확정 사항 (2026-11-10~11, 편집자)

- '절 제목' 새 쪽 시작 끔, '잠깐!' 음영 좌우 오프셋 0 — 그대로 진행
- **도판은 인디자인에서 직접 짠다.** 시안 PDF를 놓지 않는다. 회색 자리 상자에 크기와 참고할 제작지시 파일(`시안/도N-N_…` 또는 `시안/N장_…`)을 적었다. 제작지시가 없는 도판(1-2, 1-5)은 '시안 이미지 참고'로 적었다.
- **앞부속:** 1~3쪽 표제지·판권·속표지 자리(부모 페이지 없음, 인쇄 안 되는 이름표만). **4쪽부터 머리말** — 원고 미입수라 자리 문단 하나만 둔다. 1장 도비라 펼침면이 짝수 쪽에서 시작하도록 머리말 뒤에 빈 쪽이 생길 수 있다(지금은 4쪽 머리말 자리, 5쪽 빈 쪽, 6~7쪽 도비라, 8쪽 1장 본문 예상).
- **저장 위치:** `conbo > 인디자인 > 10대를 위한 부동산 교양 수업` 폴더, 파일 이름 `부동산교양수업_본문_v1.indd`. 스크립트가 국부론 파일 경로에서 사용자 폴더를 찾아 `~/인디자인/…`, `~/conbo/인디자인/…`, `~/Documents/conbo/…`, `~/Desktop/conbo/…`, `/Users/conbo/인디자인/…` 순서로 폴더를 찾는다. 같은 이름 파일이 있으면 `_2`, `_3`을 붙인다. 폴더를 못 찾거나 파일이 있는지 확인할 수 없으면 저장하지 않고 알린다(덮어쓰기 방지). 'conbo'가 사용자 홈 폴더라는 것은 추정이다.

## 스크립트가 하는 일

1. 열려 있는 《국부론 수업》 문서에서 다음을 **새 문서**로 가져온다. 원본은 고치지 않는다.
   - 문단·문자·개체·표 스타일
   - 색상 견본
   - 부모 페이지
2. 새 문서를 판형 150×214mm, 여백 위 19.5 / 아래 31 / 안쪽 27 / 바깥 22mm, 도련 3mm로 설정한다.
3. 장마다 순서대로 놓는다.
   1. 도비라 펼침면(짝수·홀수 쪽): 오른쪽 면에 도비라 자리와 장 번호·제목
   2. 본문: 첫 쪽부터 넘치는 만큼 쪽을 늘려 이어 흘린다
4. 도판 자리마다 시안과 같은 크기의 회색 인라인 상자를 넣는다. 쪽수를 실제와 가깝게 하려는 것이다.
5. 끝나면 쪽수와 확인 항목을 알린다.

## 확인 필요

- **절 제목의 새 쪽 시작을 껐다. [확정 2026-11-10, 편집자 승인]** 국부론 '대제목'은 매번 새 쪽에서 시작한다. 이번 원고는 절이 짧고 많아(1장 10개) 빈 면이 많이 생기기 때문이다. 국부론과 똑같이 하려면 '절 제목'의 [단락 시작]을 '다음 페이지'로 바꾸면 된다.
- **'잠깐!' 상자 안 문단 구분**
  - 내보낸 원고에서는 상자 안 문단이 이어 붙어 있어 구분을 확인할 수 없다. 그래서 상자 하나를 한 문단으로 넣었다.
  - 원본 Docs와 대조해 줄을 바꿔야 한다. 예: 1장 크록 상자의 "맥도날드의 창업 이야기는…"
- **번호 소제목**은 원고 번호 "1) 2) 3)"를 그대로 썼다.
- **제외한 것:** 4장 끝 편집 메모 "트럼프 이야기는 조금 민감한 내용일 수 있어서…"
- **본문 속 출처 번호** `[2-3]`, `[3-7]`은 원고대로 두었다.
- **도판:** 인디자인에서 직접 짠다(확정). 회색 자리 상자를 지우고 그 자리에 짠다.
- **쪽번호·러닝헤드**는 국부론 부모 페이지를 따른다. 앞부속은 1~3쪽 자리만 두었다(표제지·판권·속표지). 차례 자리는 두지 않는다(2026-11-11 확정).
- **인디자인 실행 검증 전이다.** 이 클라우드 환경에는 인디자인이 없어 문법 검사만 했다. 반드시 새 문서에서 결과를 확인한다.

## UXP 차이 사전 점검 기록 (2026-11-10)

인디자인 없이 코드만 보고 고쳤다. 문법 검사와 가짜 객체 실행(UXP·ExtendScript 두 경로)만 통과했고, **인디자인 실행 검증은 여전히 전이다.**

### UXP와 ExtendScript 차이 대응

| 위치 | 문제 | 원인 | 고친 방법 |
|---|---|---|---|
| 끝 알림 | UXP에서 결과 창이 안 뜰 수 있음 | UXP 스크립트에는 `alert`가 없을 수 있다 | `say()`: `alert`가 있으면 쓰고, 없으면 인디자인 대화상자로 띄운다. 전체 기록은 1쪽 왼쪽 대지의 '조판 기록' 글상자(인쇄 안 됨)에도 남긴다 |
| 스타일·견본·부모 페이지 가져오기 | 원본 파일 인자 형식이 맞지 않으면 다섯 가지 가져오기가 모두 실패 | `doc.fullName`이 ExtendScript에서는 File 객체, UXP에서는 경로 문자열이다 | 받은 값으로 먼저 시도하고, 실패하면 경로 문자열로 다시 시도 |
| 왼쪽·오른쪽 쪽 판별 | 열거형 비교가 어긋나면 안쪽·바깥 여백이 뒤바뀜 | `page.side == PageSideOptions.RIGHT_HAND` 비교 | 쪽 위치(documentOffset) 짝홀로 판별. 1쪽 시작·마주 보는 페이지 전제 |
| 스타일 속성 지정 | 속성 이름이 틀려도 조용히 넘어갈 수 있음 | UXP는 없는 속성에 값을 넣어도 오류를 내지 않을 수 있다 | 숫자·참거짓 속성은 다시 읽어 확인하고, 다르면 '확인 필요'에 남긴다 |
| 실행 | 되돌리기를 수백 번 해야 취소됨, 느림 | 명령마다 되돌리기 단계가 쌓인다 | `doScript(…, UXPSCRIPT 또는 JAVASCRIPT, …, ENTIRE_SCRIPT)`로 감쌌다. [편집 > 실행 취소] 한 번에 전체 취소. 실패하면 그냥 실행 |
| 도비라 제목 | — | `everyItem()` 일괄 지정 | 문단마다 지정으로 바꿨다(두 환경에서 같은 동작) |

### 실행하면 드러났을 오류

| 위치 | 문제 | 원인 | 고친 방법 | 기대 효과 |
|---|---|---|---|---|
| 도판 자리 상자 | 회색 상자가 윗줄 글자를 덮음 | 인라인 개체는 고정 행간(26pt) 줄에서 줄 높이를 늘리지 않는다 | '줄 위(Above Line)' 고정 개체로 넣고 가운데 정렬 | 상자 높이만큼 글이 밀려 쪽수가 실제와 가까워진다 |
| 도2-1 펼침면 | 상자 두 개가 한 줄에 겹침 | 한 문단 앞에 두 개를 넣었다 | 상자마다 문단을 나눔 | 두 칸이 위아래로 놓인다 |
| 도4-1 (156mm) | 판면(163.5mm)에 자리 문단 한 줄과 함께 들어가지 않음 → 같은 장이 400쪽까지 늘어날 수 있음 | 판면보다 큰 줄 위 개체는 어느 틀에도 들어가지 않는다 | 자리 상자 높이를 148.5mm로 줄이고 '확인 필요'에 남김. 새 틀에 글이 한 자도 안 들어가면 흘리기를 멈추고 그 쪽을 지운다 | 무한히 쪽이 늘지 않는다. 실제 도4-1은 한 면 전체로 따로 앉힌다 |
| 문서 여백 | 여백을 정하지 않음 | `marginPreferences`를 읽기만 하고 값을 넣지 않았다 | 문서 기본값과 기본 부모 페이지에 위 19.5 / 아래 31 / 안쪽 27 / 바깥 22mm, 1단 | 국부론 부모 페이지를 못 가져와도 판면이 맞는다 |
| 본문 부모 페이지 | 국부론의 '마지막' 부모 페이지를 씀 → 도비라용 등 엉뚱한 것일 수 있음 | 이름을 모른 채 순서로 골랐다 | 국부론 쪽에 가장 많이 적용된 부모 페이지 이름을 세어 같은 이름을 고른다 | 쪽번호·러닝헤드가 본문용으로 들어간다 |
| 고딕 Light 글꼴 | `fontStyle "Lt"`가 맞지 않을 수 있음 | 산돌 고딕Neo1의 스타일 이름은 번호가 붙는다(SDGothicNeoa-cLt → '03 Lt'로 추정) | 설치된 글꼴에서 '03 Lt' → 'Lt' 순서로 찾아 쓴다. '07 Bd', '06 Hv'도 같은 방식 | 글꼴이 없으면 '확인 필요'에 이름이 남는다 |
| 견본 | '잠깐!' 연노랑(C=0 M=6 Y=68 K=0) 견본 이름이 국부론에 없으면 음영 색이 비어 있음 | 견본 이름을 확인하지 못했다 | 이름으로 못 찾으면 같은 CMYK로 새로 만들고 기록 | 음영이 빠지지 않는다 |
| 보고 | 장별 시작 쪽·넘침 여부가 없었다 | — | 끝 알림과 '조판 기록'에 부모 페이지, 장별 도비라·본문 시작과 끝 쪽, 넘침 남음 여부, 문단 수 불일치를 쓴다 | 실행 뒤 점검 보고에 그대로 쓴다 |

### 디자인 변경 1건 [확정 2026-11-10, 편집자 승인]

- **'잠깐!' 음영의 좌우 오프셋을 3mm → 0으로 바꿨다.** 이전 값은 글 들여쓰기 3mm에 음영 오프셋 3mm가 더해져 음영이 판면(101mm) 밖으로 3mm씩, 모두 107mm로 나갔다. 지금은 음영 폭이 판면과 같고, 글은 들여쓰기 3mm로 안쪽 여백을 둔다. 국부론 상자의 실측 폭과는 대조하지 않았지만 이대로 진행한다.

### 실행 때 주의

- 국부론 패키지 글꼴이 `Document fonts` 폴더로만 켜져 있으면 새 문서에는 적용되지 않는다. '글꼴 없음'이 나오면 해당 글꼴을 시스템에 설치하거나, 새 문서를 국부론 패키지 폴더에 저장한 뒤 다시 연다.
- UXP는 `.idjs`, ExtendScript는 `.jsx`를 쓴다. 내용은 같다.
