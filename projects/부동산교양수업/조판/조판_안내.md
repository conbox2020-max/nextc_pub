'conbo'가 사용자 홈 폴더라는 것은 추정이다.

## 스크립트가 하는 일

1. 열려 있는 《국부론 수업》 문서에서 다음을 **새 문서**로 가져온다. 원본은 고치지 않는다.
   - 문단·문자·개체·표 스타일
   - 색상 견본
   - 부모 페이지
2. 새 문서를 판형 150×214mm, 여백 위 19.5 / 아래 31 / 안쪽 27 / 바깥 22mm, 도련 3mm로 설정한다.
3. 장마다 순서대로 놓는다.
   1. 도비라 펼침면(짝수·홀수 쪽): 오른쪽 면에 도비라 자리와 장 번호·제목
   2. 본문: 첫 쪽부터 넘치는 만큼 쪽을 늘려 이어 흘린다
4. 도판 자리마다 시안과 같은 크기의 회색 인라인 상자를 넣는다. 쪽수를 실제와 가깝게 하려는 것이다.
5. 끝나면 쪽수와 확인 항목을 알린다.

### 괄호 처리 (2026-11-11, 편집자 요청: 국부론과 같게)

- 국부론은 본문 계열 문단의 괄호 기호를 지우고 괄호 속 글자에 문자 스타일 **'한글괄호'·'영문괄호'**(Sandoll 고딕Neo1 Lt 8pt, K80, 기준선 −1pt)를 썼다(예: 매뉴팩처manufacture, 측은지심惻隱之心). 캡션·도판 출처·저서 연도·판권에는 괄호를 남겼다.
- 이번 책: 본문·본문 삽입·목록·번호 목록·잠깐 상자·절 제목·소제목·소소제목·질문 제목의 괄호 63곳을 다음처럼 나눈다.
  - **44곳 — 괄호 기호를 지우고 국부론 문자 스타일 적용.** 괄호 속에 한글·한자가 없고 영문이 있으면 '영문괄호', 나머지는 '한글괄호'.
  - **19곳 — 긴 괄호(괄호 속 한글 16자 이상): 괄호 기호를 남기고 크기만 10pt** (2026-11-11 편집자 결정). 문자 스타일 '긴괄호'(크기 10pt만 지정, 서체·색은 문단 그대로)를 괄호 기호까지 포함해 적용한다. 예: 1장 "(단, 이것이 모나코의 모든 집이나 땅의 평균 가격이라는 뜻은 아니랍니다.)", 7장 "(예: 공유 주택, 코하우징, 스마트 하우스, 제로 에너지 하우스 등)". 전체 목록은 스크립트를 만들 때 출력된다.
  - 16자가 넘는 영문 이름 3곳(The Founder, 2017 / The Wealth Report / Rudolf von Jhering)은 문장이 아니라 낱말 풀이라서 국부론의 'invisible hand'처럼 '영문괄호'로 둔다. (앞서 '긴 괄호 21곳'이라고 적은 것은 잘못 센 것이다. 16자 넘는 괄호는 모두 22곳이고, 그중 한글 19곳이 '긴 괄호'다.)
- 괄호를 남긴 곳: 참고 자료(출처 목록 12곳), 도판 자리.
- 원고 JSON은 그대로 두고, 조판 스크립트를 만들 때(`tools/make_layout_script.py`, 기준 길이 `LONG_PAREN = 15`) 바꾼다. 태그 텍스트에도 `<CharStyle:…>`로 반영했다.

## UXP 차이 사전 점검 기록 (2026-11-10)

인디자인 없이 코드만 보고 고쳤다. 문법 검사와 가짜 객체 실행(UXP·ExtendScript 두 경로)만 통과했고, **인디자인 실행 검증은 여전히 전이다.**

### UXP와 ExtendScript 차이 대응

| 위치 | 문제 | 원인 | 고친 방법 |
|---|---|---|---|
| 끝 알림 | UXP에서 결과 창이 안 뜰 수 있음 | UXP 스크립트에는 `alert`가 없을 수 있다 | `say()`: `alert`가 있으면 쓰고, 없으면 인디자인 대화상자로 띄운다. 전체 기록은 1쪽 왼쪽 대지의 '조판 기록' 글상자(인쇄 안 됨)에도 남긴다 |
| 스타일·견본·부모 페이지 가져오기 | 원본 파일 인자 형식이 맞지 않으면 다섯 가지 가져오기가 모두 실패 | `doc.fullName`이 ExtendScript에서는 File 객체, UXP에서는 경로 문자열이다 | 받은 값으로 먼저 시도하고, 실패하면 경로 문자열로 다시 시도 |
| 왼쪽·오른쪽 쪽 판별 | 열거형 비교가 어긋나면 안쪽·바깥 여백이 뒤바뀜 | `page.side == PageSideOptions.RIGHT_HAND` 비교 | 쪽 위치(documentOffset) 짝홀로 판별. 1쪽 시작·마주 보는 페이지 전제 |
| 스타일 속성 지정 | 속성 이름이 틀려도 조용히 넘어갈 수 있음 | UXP는 없는 속성에 값을 넣어도 오류를 내지 않을 수 있다 | 숫자·참거짓 속성은 다시 읽어 확인하고, 다르면 '확인 필요'에 남긴다 |
| 실행 | 되돌리기를 수백 번 해야 취소됨, 느림 | 명령마다 되돌리기 단계가 쌓인다 | `doScript(…, UXPSCRIPT 또는 JAVASCRIPT, …, ENTIRE_SCRIPT)`로 감쌌다. [편집 > 실행 취소] 한 번에 전체 취소. 실패하면 그냥 실행 |
| 도비라 제목 | — | `everyItem()` 일괄 지정 | 문단마다 지정으로 바꿨다(두 환경에서 같은 동작) |

### 디자인 변경 1건 [확정 2026-11-10, 편집자 승인]

- **'잠깐!' 음영의 좌우 오프셋을 3mm → 0으로 바꿨다.** 이전 값은 글 들여쓰기 3mm에 음영 오프셋 3mm가 더해져 음영이 판면(101mm) 밖으로 3mm씩, 모두 107mm로 나갔다. 지금은 음영 폭이 판면과 같고, 글은 들여쓰기 3mm로 안쪽 여백을 둔다. 국부론 상자의 실측 폭과는 대조하지 않았지만 이대로 진행한다.
